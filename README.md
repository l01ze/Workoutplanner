# 🏋️‍♂️ AI Workout Planner Pro

A clean, minimalist web application designed to help you build, track, and optimize your workout routines. It combines a simple drag-and-drop feeling weekly tracker with a smart AI assistant that can instantly build custom workout splits or modify your routine on the fly.

## 🌟 Key Features

* **AI Chat Assistant:** Type naturally (e.g., *"Create a 3-day push/pull/legs split"* or *"Swap squats for an alternative on Tuesday"*) to instantly generate or change your routine.
* **Weekly Schedule Grid:** View your whole week at a glance with live metrics keeping track of your total workout volume and set targets.
* **Interactive Checklist ("Today" View):** A dedicated, day-specific checklist space to check off sets and exercises as you complete them in the gym.
* **Theme Customization:** Switch easily between multiple light and dark color visual presets (Light, Dark, Ocean, Forest, Sunset) to suit your style.

---

## 🔑 Activating the AI Features

To unlock the AI chat and program generation capabilities, you will need a **Grok API key**. 

### How to set it up:
1. Get an API key from your **x.ai (Grok)** developer account dashboard.
2. Open the Workout Planner website.
3. Click on the **Settings/API** menu button in the top corner.
4. Paste your secret key token into the input field and save. 

*Note: Your API key is stored safely directly in your own browser's local storage and is never shared with third parties.*

## 📦 Evolution of the Project

### 🔴 Version 1.0 — The Foundation
* **Intelligent Client Parser:** Built a smart text-reading tool that lets you paste raw workouts (e.g., *"Monday: Bench 4x8, Squat 3x10"*) to instantly log your routines without manually tapping buttons.
* **Interactive 7-Day Grid:** Created the initial weekly overview dashboard that automatically calculates and displays your aggregate total sets per day.
* **Smart Filtering:** Programmed the engine to strip conversational noise away from text so only pure data enters your active routine space.

### 🟡 Version 1.1 — Multi-Schedules & Daily Workspaces
* **Multiple Workout Routines:** Added the ability to create, name, switch between, and archive multiple different splits (e.g., switching from a "Bulking Plan" to a "Cutting Routine").
* **Live Progress Checklists:** Introduced the interactive "Today's Workout" step-by-step check-box layout to track individual gym exercises dynamically.
* **Visual Styling Options:** Integrated a dedicated theme engine supporting 5 different distinct color visual configurations (such as Ocean and Forest mode).

### 🟢 Version 1.2 — Accounts & Layout Adjustments
* **Optional Cloud Accounts:** Added a secure profile registration system so you can optional save and access your schedules on multiple different devices.
* **Interface Stacking Fixes:** Polished the user interface to ensure pop-up menus, confirmation alerts, and timers never overlap incorrectly on smaller mobile screens.

## ⚙️ How to Run the App

1. **Clone or Download:** Save the project files to your computer.
2. **Launch:** Because the app is completely self-contained, you don't need any complex installation commands. Just double-click the main `.html` file to open it directly inside any web browser (Chrome, Safari, Edge, Firefox).
3. **Configure:** Enter your Grok key in the settings tab, and your interactive AI planner is fully active!
